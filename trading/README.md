# DayTrader — פלטפורמת מסחר יומי במניות ארה"ב

שלב 1: מסחר מדומה (paper) עם ביצוע פקודות ריאליסטי. הארכיטקטורה בנויה כך שהמעבר למסחר אמיתי
יהיה החלפה של מימוש ה-Broker בלבד. שכבת הסיכונים, ה-API והממשק נשארים כמו שהם.

## הרצה

```bash
cd trading
cp .env.example .env      # אופציונלי, כל ההגדרות כבר מוגדרות כברירת מחדל
npm install
npm run dev               # שרת על :4000, ממשק על http://localhost:5173
```

הרצה כמו בפרודקשן (השרת מגיש גם את הממשק הבנוי): `npm run build && npm start` ואז http://localhost:4000

בדיקות: `npm test`

## מקורות נתונים

| `DATA_SOURCE` | מה מקבלים |
|---|---|
| `sim` (ברירת מחדל) | שוק סינתטי: random walk עם תנודתיות משתנה, ספרד וגדלי ציטוט. עובד בלי אינטרנט ובלי מפתחות, והשוק תמיד פתוח. |
| `alpaca` | ציטוטים ועסקאות אמיתיים בזמן אמת (IEX) ונרות היסטוריים מ-Alpaca. צריך חשבון חינמי ב-alpaca.markets ומפתחות ב-`ALPACA_KEY_ID` / `ALPACA_SECRET_KEY`. במצב הזה נאכפות שעות המסחר (09:30–16:00 שעון ניו יורק). |

הביצוע במצב `alpaca` עדיין מדומה מקומית, אבל מול מחירי השוק האמיתיים.

## מה הסימולטור מדמה (ולמה הוא "מחמיר")

- **פקודות שוק** חוצות את הספרד (קנייה ב-ask, מכירה ב-bid) ומשלמות slippage שמוגדר ב-`SLIPPAGE_BPS`.
- **נזילות**: המילוי מוגבל לגודל המוצג בציטוט, כך שפקודה גדולה מתמלאת חלקית לאורך כמה ציטוטים.
- **פקודות לימיט** שממתינות בספר מתמלאות רק כשהמחיר *עובר* את הלימיט. נגיעה בלבד לא מספיקה, כי אין לנו עדיפות בתור.
- **סטופ** מופעל על ה-bid/ask ומתמלא כמו פקודת שוק.
- **פקודות Bracket**: כניסה עם take-profit ו-stop-loss בקשר OCO. היציאות מופעלות רק אחרי שהכניסה מתמלאת, ומתעדכנות במילוי חלקי.
- **מרג'ין** (`MARGIN_MODEL`):
  - `intraday` (ברירת מחדל): כללי FINRA החדשים, בתוקף מ-4.6.2026. אין מגבלת עסקאות יומיות ואין דרישה ל-$25K.
    ההון צריך לכסות 25% מפוזיציות לונג ו-30% משורט, כלומר עד בערך פי 4. מתחת ל-$2,000 אין מינוף ואין שורט.
    כשההון יורד מתחת לדרישה, החשבון נכנס ל-margin call ומותרות רק פקודות סגירה.
  - `pdt`: הכלל הישן (4x מעל $25K, 2x מתחת, וחסימה של עסקה יומית רביעית בתוך 5 ימים). מיועד לברוקר שעוד לא עבר לכללים החדשים.
- **חשבון מזומן**: בלי מינוף ובלי שורט.
- **סוף יום**: פקודות DAY פגות, ורווח/הפסד יומי מתאפס.
- **עמלות** (ברירת מחדל: IBKR Pro Fixed):
  - $0.005 למניה, מינימום $1 לפקודה, ולא יותר מ-1% משווי העסקה. המינימום נגבה פעם אחת לפקודה, גם כשהיא מתמלאת בכמה חלקים.
  - במכירה נוספות עמלת SEC ($20.60 לכל מיליון דולר) ועמלת FINRA TAF ($0.000195 למניה, עד $9.79).
  - כל העלויות יורדות מהמזומן ומהרווח הממומש, ומוצגות בכותרת ("Fees today") ובטבלת המילויים.

## שכבת סיכונים (פועלת מול כל ברוקר, גם אמיתי)

- `MAX_DAILY_LOSS`: אחרי הפסד יומי בגודל הזה מותרות רק פקודות סגירה.
- `MAX_RISK_PER_TRADE`: כל פוזיציה חדשה חייבת stop-loss, וההפסד עד הסטופ מוגבל לסכום הזה.
  כפתור Size בכרטיס הפקודה מחשב את מספר המניות המקסימלי, כולל עמלות הלוך-חזור.
- `MAX_ORDER_NOTIONAL` ו-`MAX_POSITION_NOTIONAL`: תקרות לגודל פקודה ולגודל פוזיציה.
- `FLATTEN_MINUTES_BEFORE_CLOSE`: סגירה אוטומטית של כל הפוזיציות לפני סוף המסחר. פועל רק עם שעות מסחר אמיתיות.
- פקודה שרק מקטינה פוזיציה תמיד עוברת, כדי שאף פעם לא ננעלים בתוך פוזיציה מפסידה.

ברירות המחדל מותאמות לחשבון של $5,000: סטופ חובה, עד $50 סיכון לעסקה, עד $150 הפסד ביום, ועד $10,000 לפוזיציה.
אחרי שינוי `STARTING_CASH` צריך ללחוץ על **Reset** בכותרת, כי מצב החשבון נשמר בין הרצות.

## ממשק

רשימת מעקב, גרף נרות של דקה עם VWAP וקווים לפקודות ולמחיר הכניסה, וכרטיס פקודה (שוק, לימיט, סטופ, סטופ-לימיט, Bracket).
יש גם מחשבון גודל פוזיציה לפי סיכון ב-$, טבלאות של פוזיציות, פקודות ומילויים, וכפתור "Flatten all".
לחיצה על הגרף ממלאת את המחיר בכרטיס הפקודה.

## מבנה

```
server/src/
  market/      feed.ts (ממשק + צבירת נרות), simFeed.ts, alpacaFeed.ts, clock.ts
  broker/      broker.ts (ממשק), paperBroker.ts, stateStore.ts (שמירה ל-data/*.json)
  risk/        riskManager.ts
  tradingService.ts   מחבר נתונים + ברוקר + סיכונים, וזרם אירועים
  api/server.ts       REST + WebSocket (/ws)
web/src/       React + lightweight-charts
```

## השלבים הבאים

1. **`AlpacaBroker`**: מימוש של ממשק `Broker` מול ה-Trading API של Alpaca. קודם מול חשבון ה-paper שלהם, ורק אחר כך live.
   הממשק כבר אסינכרוני, וה-types שלנו (Order, Bracket, TIF) תואמים את המודל שלהם.
2. אימות משתמש לפני שמחברים כסף אמיתי. כרגע אין שום אבטחה על ה-API, ולכן אסור לחשוף אותו לרשת.
3. יומן מסחר וסטטיסטיקות: win rate, R ממוצע, ו-P&L לפי שעה.
4. קיצורי מקלדת לכניסה ויציאה מהירות.
